# i18n（言語切替）Design Spec

**Date:** 2026-06-24
**Branch:** feature/createNote（新ブランチを切って作業）
**Status:** Approved

---

## 概要

全 22 画面の UI テキストを日本語/英語で切り替え可能にする。
言語設定は `users` テーブルに保存し、ログイン後は `localStorage` でキャッシュする。
切り替え反映タイミング: **次のページ遷移**（navigate() による再マウントで自然に適用）。

---

## 対象言語

| コード | 言語 | デフォルト |
|--------|------|-----------|
| `'ja'` | 日本語 | ✅ |
| `'en'` | English | — |

---

## 非目標

- ブラウザロケール自動検出
- 3言語以上
- エラーメッセージの翻訳（日本語固定のまま）
- ログインページのi18n対応（言語未確定のため日本語固定）
- RTL レイアウト対応

---

```sql
-- migrations/009_add_language_to_users.sql

  ADD language NVARCHAR(10) NOT NULL DEFAULT 'ja';
```


### 2-4. DTO: UpdateProfileRequest（新設または既存拡張）

`backend/ScheduleApp.Api/Models/Dtos/UpdateProfileRequest.cs` — `Language` プロパティ追加:

```csharp
public string Language { get; set; } = "ja";
```

確認: 現在の `UpdateProfileRequest` に何が入っているかは実ファイルを読んで確認すること。

### 2-5. UserSettingService

`UpdateProfileAsync` 内で `user.Language = request.Language;` を追加する。
`MapToResponse` で `Language = user.Language` をマッピングする。

### 2-6. AuthService

ログイン時の `LoginResponse` 生成で `Language = user.Language` をセットする。

### 2-7. UserSettingRepository

`GetByIdAsync` で `language` カラムをマップする（EF Core の場合は自動）。
マイグレーション後に EF のモデルスナップショットも更新が必要かを確認すること。

## 3. フロントエンド: `utils/i18n.ts`（新規）

### 3-1. 公開 API

```typescript
type Lang = 'ja' | 'en';

export function getLang(): Lang
export function setLang(lang: Lang): void          // localStorage 更新のみ
export function t(key: string): string             // 静的文言ルックアップ
export function months(): string[]                  // 12要素 (index 0 = 1月)
export function daysShort(): string[]               // 7要素 (index 0 = 日)
export function daysLong(): string[]                // 7要素 (index 0 = 日曜日)
export function fmtYearMonth(year: number, month: number): string
  // ja: '2026年6月' / en: 'June 2026'
export function fmtMonthLabel(month: number): string
  // ja: '6月'      / en: 'Jun'
export function fmtFullDate(date: Date): string
  // ja: '2026年6月24日(火)' / en: 'Tue, Jun 24, 2026'
```

### 3-2. 初期化

```typescript
let currentLang: Lang = (localStorage.getItem('language') as Lang) ?? 'ja';
```

`setLang` は `localStorage.setItem('language', lang)` + `currentLang = lang` のみ実行する。
ページ再描画は呼び出し側（プロフィール設定）の navigate() に委ねる。

### 3-4. 日付フォーマットヘルパー実装

```typescript
const MONTHS_JA  = ['1月','2月','3月','4月','5月','6月','7月','8月','9月','10月','11月','12月'];
const MONTHS_EN  = ['January','February','March','April','May','June','July','August','September','October','November','December'];
const MONTHS_EN_SHORT = ['Jan','Feb','Mar','Apr','May','Jun','Jul','Aug','Sep','Oct','Nov','Dec'];

const DAYS_SHORT_JA = ['日','月','火','水','木','金','土'];
const DAYS_SHORT_EN = ['Su','Mo','Tu','We','Th','Fr','Sa'];
const DAYS_LONG_JA  = ['日曜日','月曜日','火曜日','水曜日','木曜日','金曜日','土曜日'];
const DAYS_LONG_EN  = ['Sunday','Monday','Tuesday','Wednesday','Thursday','Friday','Saturday'];

export function months(): string[] {
  return currentLang === 'ja' ? MONTHS_JA : MONTHS_EN;
}

export function daysShort(): string[] {
  return currentLang === 'ja' ? DAYS_SHORT_JA : DAYS_SHORT_EN;
}

export function daysLong(): string[] {
  return currentLang === 'ja' ? DAYS_LONG_JA : DAYS_LONG_EN;
}

export function fmtYearMonth(year: number, month: number): string {
  // month: 1-indexed
  return currentLang === 'ja'
    ? `${year}年${month}月`
    : `${MONTHS_EN[month - 1]} ${year}`;
}

export function fmtMonthLabel(month: number): string {
  // month: 1-indexed, 短縮形
  return currentLang === 'ja'
    ? `${month}月`
    : MONTHS_EN_SHORT[month - 1];
}

export function fmtFullDate(date: Date): string {
  const y = date.getFullYear();
  const m = date.getMonth() + 1;
  const d = date.getDate();
  const dow = date.getDay();
  return currentLang === 'ja'
    ? `${y}年${m}月${d}日(${DAYS_SHORT_JA[dow]})`
    : `${DAYS_SHORT_EN[dow]}, ${MONTHS_EN_SHORT[m - 1]} ${d}, ${y}`;
}
```
